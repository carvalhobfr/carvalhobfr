These figures describe the product, as published by Media Capital, not my individual contribution. Sources: [Media Capital, Fire TV launch](https://mediacapital.pt/tvi-player-chega-a-amazon-fire-tv/), [2024 report](https://mediacapital.pt/wp-content/uploads/2025/05/deae7d5f9aed81ae1323fef2d4276ac8.pdf), [MC News](https://mcnews.iol.pt/geral/21-05-2025/o-tvi-player-mudou-experimente-ja-as-novas-funcionalidades), [ECO](https://eco.sapo.pt/2026/03/29/tvi-acelera-sic-ainda-a-procura-de-futuro/).

## Independent projects

- **[Orbit](https://github.com/carvalhobfr/orbit-releases)** · A native macOS command center in Swift (macOS 14+): workspaces, a rearrangeable menu bar panel, a command palette and Mac health. Closed source; builds are published at [orbit-releases](https://github.com/carvalhobfr/orbit-releases/releases).<br>
  [![Orbit release](https://img.shields.io/github/v/release/carvalhobfr/orbit-releases?style=flat-square&labelColor=30363d&color=57606a&label=release)](https://github.com/carvalhobfr/orbit-releases/releases/latest)
- **[Conclave](https://github.com/carvalhobfr/conclave-ai)** · Open source (MIT). A PR companion that turns code changes into reviewable evidence: local and deterministic, no API key and no telemetry, read-only, with findings that point to a file and line. TypeScript, Node.js 20+.<br>
  [![npm version](https://img.shields.io/npm/v/conclave-ai?style=flat-square&labelColor=30363d&color=57606a&label=npm)](https://www.npmjs.com/package/conclave-ai) [![npm downloads per month](https://img.shields.io/npm/dm/conclave-ai?style=flat-square&labelColor=30363d&color=57606a&label=downloads%2Fmonth)](https://www.npmjs.com/package/conclave-ai)
- **[VAST Inspector](https://matheuscarvalho.me/en/tools/vast-inspector)** · A free tool for CTV ad tech: decode VAST tag URLs, review query parameters and catch common player-debugging issues. Runs locally in the browser.
- **[Pokepilot](https://github.com/carvalhobfr/pokepilot)** · Work in progress. Bots play the real Pokémon Blue ROM on an emulator, and every bit of progress is verified in cartridge RAM instead of trusted from a script. Python, PyBoy.
